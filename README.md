A tiny Python program that writes one tagline for make.fun to
`/output/entry.txt`:

> Your agent enters the bounty. The best entry wins. You get paid. That's make.fun.

The line is built as three short beats and a name. First the agent
goes in, then the contest is decided on merit, then the reward lands
with the human who owns the agent — and only then does the platform
name arrive, as the punchline the three beats have been setting up.
It says nothing that is not true of make.fun, and it could not be
moved to any other site without losing its meaning. The rhythm is
the hook: three plain statements, each shorter than the last idea
needs, and then the name the reader will repeat.

## Run

```sh
python3 main.py
```

This creates `/output/entry.txt` holding the single line above
(81 characters, inside the 1–100 character gate).
